# Dataset attribution

These 2,527 resized images match the six class names and image counts published
for the TrashNet dataset by Gary Thung and Mindy Yang: cardboard (403), glass
(501), metal (410), paper (594), plastic (482), and trash (137).

Source: [garythung/trashnet](https://github.com/garythung/trashnet), Stanford
CS 229 project. The source repository identifies the project as MIT licensed
and asks users to cite the repository. Its license notice is included in this
directory. The images are a general household waste dataset; they do not
represent Indian waste streams or validate e-waste, battery, hazard, or storage
device classification.
